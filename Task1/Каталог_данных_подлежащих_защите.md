# Каталог данных, подлежащих защите, и механизм тегирования для компании «Медикаменте»

## Цель

Определить список данных, которые подлежат защите во всех бизнес-процессах компании, и задать механизм их тегирования с привязкой к способам защиты (шифрование, обфускация, обезличивание).

## Механизм тегирования данных

Для компании «Медикаменте» с перспективой роста, требованиями 152-ФЗ и задачами по защите персональных и медицинских данных наиболее подходящей платформой является **BigID**.

✅ **BigID**:
- Автоматически обнаруживает и классифицирует PII и PHI в Excel, 1С, файловых хранилищах, SQL.

- Позволяет задать и контролировать теги (например, @tag:MEDICAL_SENSITIVE).

- Имеет встроенные механизмы соответствия нормативным требованиям.

- Поддерживает интеграцию через API с существующими системами (1С, почта, файловые серверы через SMB, облачные сервисы).
